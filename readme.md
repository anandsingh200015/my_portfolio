# Anand Srinet: Portfolio

Personal portfolio built as a single static page (`index.html`) with a Spatial UI theme.

- Home: about, experience, career timeline, skills, certifications, education
- Projects page with filters and detail views
- Search (`/`), shortcuts (`H` home, `P` projects)

The "Ask about Anand" assistant only appears inside claude.ai. It stays hidden elsewhere until a backend is added.
